# Beyond the classification

Published theorems from outside the classification of finite simple groups, formalized in Lean 4 on top of the [CFSG corpus](https://github.com/AxiomMath/CFSG/tree/69cb972f587a3ecc035e092253167ff2e303c962) (AxiomMath/CFSG at commit 69cb972).

Every result is in two forms. [`conditional/`](conditional) proves it with the corpus theorems it uses taken as hypotheses, so it builds without the corpus proofs. [`unconditional/`](unconditional) supplies those hypotheses from the corpus, so the theorem depends on no assumption beyond Lean's standard axioms (`propext`, `Classical.choice`, `Quot.sound`). Both build against the corpus at commit 69cb972. The Lean docstring of each headline theorem repeats its statement and source.

**Versions.** Lean `v4.35.0-rc3` (`lean-toolchain`), Mathlib `b63f6e8`, Tau Ceti `6e0c6ac` and the CFSG corpus at AxiomMath/CFSG `69cb972`, as pinned in `conditional/lakefile.toml` and `unconditional/lakefile.toml`.

## Formal challenges

Each result has two challenge files in `conditional/Challenge/<Result>/`. A challenge states the result with `sorry` as
its proof, together with every definition it needs.

| Challenge | States the result | Proved by |
|---|---|---|
| `Clean.lean` | exactly as in the paper | `unconditional/` |
| `Fast.lean` | with the corpus theorems it uses as extra hypotheses | `conditional/` |

Lean's comparator checks a proof against its challenge. It confirms that the proof proves exactly the challenge's
statements, uses only the axioms `propext`, `Classical.choice` and `Quot.sound`, and passes the kernel. Each result has
one configuration in `conditional/comparator/` and one in `unconditional/comparator/`. To check a result, copy its
configuration to `comparator.json` in that folder and run `lake comparator` (Linux only). Tame fusion systems has two
configurations, one for each half of Theorem 3.8.
